# Правила чайного клуба — плакат на нескольких языках

Плакат «Правила для посетителей чайного клуба» (A4) в оригинальном дизайне, переведённый на грузинский язык
и собранный из одного источника текста. Из одного набора данных получаются:

| Файл | Для чего |
| --- | --- |
| `dist/tea-club-rules-ka.pdf` | **Грузинская версия для печати**: A4, векторный текст, шрифты вшиты (TrueType), графика 300 dpi |
| `dist/tea-club-rules-ka-print.png` | Растровая версия 2480×3508 (300 dpi), для типографии и больших экранов |
| `dist/tea-club-rules-ka-screen.png` | Лёгкая версия 1080 px по ширине: Instagram, Telegram, экран на ресепшене |
| `dist/tea-club-rules-ka.docx` | Редактируемый текст для сайта и соцсетей + таблица «Русский — ქართული» для вычитки |
| `dist/tea-club-rules-ru.*` | Обновлённая русская версия (с новыми правилами). Это исходник, по ней удобно согласовать смысл |

Оригинал, из которого взят дизайн: `source/original-ru.pdf`.

Документы:

- [`docs/product-analysis.md`](docs/product-analysis.md): найденные слепые зоны и принятые решения, крайние сценарии,
  оценка по эвристикам Нильсена, закон Хика, где в коде SOLID, DRY и KISS.
- [`docs/translation-notes.md`](docs/translation-notes.md): глоссарий, обоснование каждой грузинской формулировки и её
  обратный перевод на русский.

## Как поменять текст

Весь текст лежит в `content/locales/<язык>.json`, вёрстка его не содержит.

1. Откройте `content/locales/ka.json` (или `ru.json`) и поправьте нужную строку.
   `**так**` выделяет жирным. Кавычки: в грузинском `„…“`, в русском `«…»`. Тире: `—`.
2. Запустите `npm run check`: тесты проверят текст, затем соберутся PDF, PNG и DOCX.
3. Если текст перестал помещаться, сборка остановится и назовёт пункт, который вылез за край.
   Сократите формулировку или уменьшите кегль в `template/poster.css` (`--body-size`).

Порядок пунктов, иконки и разбиение на блоки задаются в `content/layout.json` и одинаковы для всех языков.

### Добавить пункт

1. В `content/layout.json` добавьте `{ "id": "newRule", "icon": "имя-иконки" }` в нужный блок.
2. Добавьте текст `"newRule": "…"` в тот же блок **каждого** файла в `content/locales/`.
   Если забыть один язык, тест назовёт пропущенный ключ.
3. Иконка — SVG-файл в `assets/icons/`. Подходят иконки [Tabler](https://tabler.io/icons) (outline):
   скачайте SVG и положите в папку под тем же именем.

### Добавить язык (например, английский)

1. Скопируйте `content/locales/ru.json` в `en.json`, поменяйте `meta` (`"lang": "en"`, `"bcp47": "en-US"`,
   `"role": "translation"`, `"name": "English"`) и переведите строки.
2. `npm run check`. Код менять не нужно: шрифт Noto Sans уже покрывает латиницу.
   Для языка с новой письменностью добавьте шрифт в `assets/fonts/faces.json` и стек в `src/config.mjs`.

### Включить блок «Запись и вопросы»

Блок с телефоном и Instagram подготовлен, но выключен. Впишите контакты в `contacts` в `ka.json` и `ru.json`
(вместо `___`) и поменяйте в `content/layout.json` у секции `contacts` значение `"enabled": false` на `true`.
Тест не даст напечатать плакат, пока в тексте остаются прочерки `___`.

## Сборка

Нужны Node.js 20+ и Chromium для Playwright.

```bash
npm install
npx playwright install chromium   # один раз, если браузер ещё не установлен
npm run check                     # тесты + сборка всех языков в dist/
npm run build -- ka               # только грузинская версия
npm run preview -- ka             # только HTML в build/ka/poster.html, без проверок (для быстрой правки стилей)
npm test                          # только тесты
```

## Как устроено

```text
content/
  layout.json            структура: блоки, порядок, иконки (без текста)
  locales/ru.json        исходный текст
  locales/ka.json        грузинский перевод
template/poster.css      вёрстка A4 (размеры в мм и pt)
assets/                  шрифты, иконки, фон, логотип
src/
  config.mjs             пути, размер страницы, шрифты, форматы PNG
  content.mjs            загрузка и проверка текста, модель документа
  typography.mjs         неразрывные пробелы, жирный, Мтаврули в заголовках
  render-html.mjs        модель → HTML-страница плаката
  render-docx.mjs        модель → DOCX
  export-browser.mjs     HTML → PDF и PNG, проверка «всё помещается»
  build.mjs              сборка всех языков
test/                    проверки контента, типографики и шрифтов
tools/                   разовые скрипты: извлечение графики из оригинала, статические шрифты
```

Сборка останавливается с понятным сообщением, если:

- в каком-то языке не хватает строки или осталась строка, которой нет в макете;
- в тексте прямые кавычки, двойные пробелы, дефис вместо тире или чужие буквы (кириллица в грузинском);
- в шрифтах нет глифа для какого-то символа;
- текст не помещается на лист или в бежевую панель.

### Ассеты

Фон (узор), логотип и лист извлечены из оригинального PDF скриптом, русский текст и старые иконки из фона удалены:

```bash
python3 -I tools/extract_assets.py source/original-ru.pdf assets/img     # нужны numpy, Pillow, pypdf, poppler-utils
python3 -I tools/make_font_instances.py assets/fonts                     # нужен fonttools
```

Статические начертания шрифтов нужны потому, что вариативные шрифты Chromium вшивает в PDF как Type 3,
а такие шрифты типографии иногда не принимают на предпечатной проверке.
